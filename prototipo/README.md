# Protótipo original (Claude Design)

Arquivos exportados do projeto **Jogo Educativo de Átomos** criado no Claude Design,
mantidos aqui sem alterações como referência visual e de regras do jogo.

- `nucleo-jogo-de-moleculas.dc.html` — tela única com Início, Laboratório, Coleção, Missões e Perfil
  (formato `.dc.html` do Claude Design, que depende do runtime do editor para rodar).
- `nucleo-data.js` — os 118 elementos da tabela periódica e as 26 substâncias do catálogo.

O jogo jogável, reescrito em React, fica em `src/`.
